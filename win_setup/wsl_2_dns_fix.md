# 🛠 Fixing WSL DNS Issues When Using VPN

## 🧩 Problem

After connecting to a VPN on Windows, **WSL (Ubuntu, Debian, etc.) may lose network connectivity**, usually due to broken **DNS resolution**.

This guide walks you through disabling WSL's auto-generated DNS config and setting a static one manually.

---

## ⚠️ Important

> 🔁 **Steps 1–3 must always be done first!**
> Skipping them can result in data loss or inability to restore DNS settings.

---

## 🔧 Manual DNS Fix (Required)

These first steps **must be performed manually** to ensure your system DNS settings are backed up and safely replaced.

---

### 1. Backup the current `resolv.conf`

```bash
sudo cp /etc/resolv.conf /etc/resolv.conf.new
```

---

### 2. Unlink the autogenerated `resolv.conf`

```bash
sudo unlink /etc/resolv.conf
```

> ⚠️ By default, `resolv.conf` in WSL is a **symbolic link**, typically pointing to `/run/resolvconf/resolv.conf`.
> The `unlink` command removes the symlink, not the actual file it points to.

---

### 3. Restore your backup

```bash
sudo mv /etc/resolv.conf.new /etc/resolv.conf
```

---

## 🔀 Choose One of Two Methods to Set DNS

After the manual fix above, you can choose **how** to apply your DNS configuration:

* **✅ Option A: Quick Automatic Fix**
  Run a script that disables DNS auto-generation, adds static DNS, and locks the config file.

* **🛠 Option B: Manual Configuration**
  Manually edit WSL config files and enter DNS server IPs yourself.

Pick the method that suits your workflow best.

---

### ✅ Option A: Quick Automatic Fix (Run inside WSL)

This script handles everything in one go:

```bash
# Disable automatic resolv.conf generation
sudo tee /etc/wsl.conf > /dev/null << EOF
[network]
generateResolvConf=false
EOF

# Set static DNS servers
sudo tee /etc/resolv.conf > /dev/null << EOF
nameserver 8.8.8.8
nameserver 8.8.4.4
nameserver 1.1.1.1
nameserver 1.0.0.1
nameserver 9.9.9.9
nameserver 149.112.112.112
nameserver 208.67.222.222
EOF

# Prevent future overwrites
sudo chattr -f +i /etc/resolv.conf
```

---

### 🛠 Option B: Manual DNS Configuration

#### 4. Disable automatic DNS in WSL

```bash
sudo nano /etc/wsl.conf
```

Paste:

```ini
[network]
generateResolvConf=false
```

---

#### 5. Edit `/etc/resolv.conf`

```bash
sudo nano /etc/resolv.conf
```

Delete any autogenerated lines, and replace them with your DNS settings, for example:

```conf
nameserver 10.0.0.1
nameserver 8.8.8.8
nameserver 8.8.4.4
```

---

### 👀 View Configuration Files

Before restarting WSL, you can verify your settings:

```bash
cat /etc/wsl.conf
cat /etc/resolv.conf
```

Make sure the files reflect the changes you made.

---

### 🔁 Restart WSL

Run the following in **PowerShell** or **Command Prompt** to apply changes by restarting WSL:

```powershell
wsl --shutdown
```

Then reopen your WSL terminal.
